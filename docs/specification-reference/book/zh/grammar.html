[contract.grammar]

文法索引

[contract.grammar.intro]

本页集中展示核心文法，便于连续阅读。每条规则的名称都链接到所属主题页，在那里可以查看语义、示例和能力边界。

记号说明见文法记号；运算优先级见条件表达式。本页与各主题页由同一份文法定义生成。

[contract.grammar.syntax]

Syntax
Specification :=
      FunctionContract
    | TypeInvariant
    | ContractStatement

FunctionContract :=
      Precondition
    | Postcondition

Precondition :=
      # [ precondition ( Condition ) ]

Postcondition :=
      # [ postcondition ( ResultPredicate ) ]

ResultPredicate :=
      | IDENTIFIER (: Type)? | Condition

TypeInvariant :=
      # [ invariant ( Condition ) ]

ContractStatement :=
      Assertion
    | Assumption

Assertion :=
      contract_assert ! ( Condition ) ;

Assumption :=
      contract_assume ! ( Condition ) ;

Condition :=
      Expr

Expr :=
      Literal
    | Path
    | self
    | ( Expr )
    | UnaryOp Expr
    | Expr BinaryOp Expr
    | Expr . Field
    | Expr [ Expr ]
    | Expr ( Arguments? )
    | Expr . IDENTIFIER ( Arguments? )
    | Quantifier
    | Implication
    | OldExpression

Arguments :=
      Expr (, Expr)* ,?

Field :=
      IDENTIFIER
    | TUPLE_INDEX

UnaryOp :=
      ! | - | * | & | & mut

BinaryOp :=
      + | - | * | / | % | << | >> | & | ^ | | | == | != | < | <= | > | >= | && | ||

Quantifier :=
      (forall | exists) ! ( QuantifierPredicate )
    | each ! ( IDENTIFIER : Type EachDomain ; Condition )

QuantifierPredicate :=
      | IDENTIFIER : Type | Condition

Implication :=
      Condition ==> Condition
    | implies ( Condition , Condition ,? )

OldExpression :=
      old ( Expr ,? )
