词法规则

规约写在 Rust 源码中。函数契约和类型不变式使用属性；语句标注和量词使用宏调用。注释不用于引入规约。

词法单元与标识符

标识符、字面量、空白和注释遵循 Rust 的词法规则。空白和普通注释可以出现在 Rust 允许的词法单元之间。规约语言没有引入独立的字面量记法或数学 Unicode 运算符。

文法中的以下名称引用 Rust 语法：

名称含义示例
IDENTIFIER标识符x、result、limit
Type类型u8、&T、Vec<i32>
Literal字面量表达式true、16、0u8
Path表达式路径x、u8::MAX
TUPLE_INDEX元组字段索引pair.0 中的 0

绑定引入的名称遵循 Rust 的作用域规则。后置条件中的 result 是普通参数名，可以换成其他标识符。类型不变式中的 self 指代被描述的值。

文法记号

Syntax 块使用紧凑的扩展 BNF（EBNF）。带边框的等宽文本表示源码中的字面词法单元；带链接的名称表示非终结符。

记号含义
A := B用 B 定义 A
A BA 后接 B
A | BA 或 B
A?A 出现零次或一次
A*A 出现零次或多次
(A B)对文法元素分组

带边框的 (、) 或 | 是源码词法单元，不是文法运算符。Arguments? 允许省略参数列表；","? 允许尾随逗号。Show syntax diagrams 按钮显示同一产生式的铁路图。

文法采用不带路径限定的名称、圆括号宏调用和简单参数绑定。Expr 产生式描述表达式结构，分组由 Rust 的运算符优先级决定；它不是覆盖全部 Rust 表达式的无歧义解析文法。

示例

#[precondition(x /* input */ < 16)]
#[postcondition(|result: u8| result >= x)]

注释分隔词法单元，不改变前置条件。第二个属性中的竖线界定返回值绑定。

实现状态

宏使用 syn::Expr 解析表达式，其接受的形式多于这份紧凑文法列出的内容。Rust 类型检查、借用检查和后续的前端提取进一步限制可接受的规约。

在契约的词法单元中，implies 会被改写为内部标记；后置条件还会改写 old。改写作用于标识符，也会影响无关绑定、字段或方法中使用的同名标识符。参见名称改写。

各页的实现状态说明已支持的处理阶段及其边界。识别或提取某种构造，本身不代表其证明义务一定能够完成。
