# 实现说明

本页记录开发中前端的共同实现特征。各构造的具体支持情况在对应参考页面中说明。

{{#rule contract.constraints.intro}}

## 内部表示

规约须满足表面语法、Rust 类型与借用规则，以及提取过程要求的结构。条件返回 `bool`；除类型不变式方法外，规约闭包均受 `Fn + Copy` 约束。

普通构建会移除规约，因此该模式下编译成功不构成规约通过验证模式检查的证据。

## 名称改写 <a id="name-rewriting"></a>

在规约宏处理的 token 中，`implies` 和后置条件里的 `old` 会被递归替换。将这些名称用于无关绑定、字段或方法可能与改写发生冲突；通用调用语法不能绕过专用接口的约束。

## 尚待覆盖的方向

当前规约接口没有提供循环不变式、循环与递归终止度量、读写足迹与修改集合、权限与借用契约、异常退出契约、模块契约，以及外部接口补充规约。

实现与样例来源见[实现依据与测试覆盖](sources.md)；文法沿用的 Rust 语法见[词法规则](notations.md#rust-syntax)。
