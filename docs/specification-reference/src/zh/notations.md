# 词法规则

规约写在 Rust 源码中。函数契约和类型不变式使用属性；语句标注和量词使用宏调用。注释不用于引入规约。

## 词法单元与标识符 <a id="rust-syntax"></a>

标识符、字面量、空白和注释遵循 Rust 的词法规则。空白和普通注释可以出现在 Rust 允许的词法单元之间。规约语言没有引入独立的字面量记法或数学 Unicode 运算符。

文法中的以下名称引用 Rust 语法：

| 名称 | 含义 | 示例 |
| --- | --- | --- |
| `IDENTIFIER` | 标识符 | `x`、`result`、`limit` |
| `Type` | 类型 | `u8`、`&T`、`Vec<i32>` |
| `Literal` | 字面量表达式 | `true`、`16`、`0u8` |
| `Path` | 表达式路径 | `x`、`u8::MAX` |
| `TUPLE_INDEX` | 元组字段索引 | `pair.0` 中的 `0` |

绑定引入的名称遵循 Rust 的作用域规则。后置条件中的 `result` 是普通参数名，可以换成其他标识符。类型不变式中的 `self` 指代被描述的值。

## 文法记号 <a id="notation"></a>

Syntax 块使用紧凑的扩展 BNF（EBNF）。带边框的等宽文本表示源码中的字面词法单元；带链接的名称表示非终结符。

| 记号 | 含义 |
| --- | --- |
| `A := B` | 用 B 定义 A |
| `A B` | A 后接 B |
| `A \| B` | A 或 B |
| `A?` | A 出现零次或一次 |
| `A*` | A 出现零次或多次 |
| `(A B)` | 对文法元素分组 |

带边框的 `(`、`)` 或 `|` 是源码词法单元，不是文法运算符。`Arguments?` 允许省略参数列表；`","?` 允许尾随逗号。**Show syntax diagrams** 按钮显示同一产生式的铁路图。

文法采用不带路径限定的名称、圆括号宏调用和简单参数绑定。`Expr` 产生式描述表达式结构，分组由 Rust 的[运算符优先级](expressions.md#operators)决定；它不是覆盖全部 Rust 表达式的无歧义解析文法。

## 示例

```rust,ignore
#[precondition(x /* input */ < 16)]
#[postcondition(|result: u8| result >= x)]
```

注释分隔词法单元，不改变前置条件。第二个属性中的竖线界定返回值绑定。

## 实现边界

- **前端 `rust-llbc`**：沿用 Rust 词法、表达式解析以及类型与借用检查。
- **后端 `llbc-why3`**：处理提取后的表示，不直接处理这些词法形式。

### 尚待补齐

**区分标记与普通名称（前端）。** 当前按名称替换 `implies` 和后置条件中的 `old`，会误改普通 Rust 名称。例如 `#[postcondition(|r| r == value.old())]` 中的 `.old()` 即使是用户定义的方法，也会受到替换，导致展开失败。名称处理需要保留普通方法调用，同时识别规约标记，见[名称改写](constraints.md#name-rewriting)。
